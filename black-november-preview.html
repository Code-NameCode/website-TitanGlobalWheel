What you're approving — looks and behaviour

The rules below are already active in this preview, so what you see is what ships.

Pop-up behaviour

Trigger
Opens ~2.5 s after the page loads
Frequency
Once per visit — closing it keeps it closed for the whole session
Close
✕ button, clicking outside, or the Escape key
While open
Page scroll is paused; the ad carries its own scroll if a screen is short

Sidebar behaviour

Rest state
Slim "BLACK NOVEMBER" tab on the right edge — nearly invisible
Expand
Hover (or tap) opens the specials card; ✕ hides it for 7 days
Count
Strictly one sidebar per page, injected by one shared script
Mobile
Hidden entirely below ~1100 px — phones only see the pop-up

Where ads run (default)

Pop-up
Homepage only — once per visit
Sidebar
Main root pages (home, products, tyres, rims, industries, contact, news, events…)
Untouched
Policy pages, 404, blog articles, nav, sitemap

Integration plan (only after your OK)

  • One shared stylesheet + one script: css/promo-bn.css, js/promo-bn.js — no libraries
  • Flyers already copied to clean URLs: src/promos/black-november-2026-1/2.jpg
  • New specials.html (full specials list, site chrome, sitemap entry) is already live on the site
  • Two small tags per page; nothing else on live pages changes
  • Easy end date: delete the two tags (or we add a built-in end date) when the promo closes

Review checklist

  • Popup A (campaign style) — typography, colours, featured tyres
  • Popup B (real flyer in a frame) — the alternative if you prefer the actual artwork
  • Sidebar tab → expand → dismiss, then "Restore sidebar" above
  • Click ENQUIRE TODAY or "See all specials" → lands on the new specials page
  • Narrow the window under 640 px: popup becomes a bottom sheet, sidebar hides

Copy used in the ads

  • Featured: SUPREME TFC, OPTITRAC, DYNA TORQUE II, MXL — straight from your flyers
  • "+40 more models on special this November"
  • Every CTA — Enquire Today and "See all specials" — opens the new specials page with the full 46-model list; from there visitors choose to enquire, call or email
  • No prices invented — the flyers' "enquire" model is kept
